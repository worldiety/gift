Basic components display one piece of content or take one input. All of them live in package `ui`.

**Content**

- [Text](text/): labels, headings and paragraphs, with wrapping, line limits and truncation.
- [Icon](icon/): a monochrome symbol from the outline or solid set, tinted with a color.
- [Image](image/): one picture from a file or a URL, loaded in the background.
- [SVG Image](svg-image/): a vector picture from an SVG document, sharp at any size.
- [Badge](badge/): a small capsule with a count or a one-word status.
- [Divider](divider/): a horizontal hairline between groups of content.
- [Progress Bar](progress-bar/): how much of a task is done, or an indeterminate bar.
- [Progress Ring](progress-ring/): how much of a task is done as a ring, or the spinner of iOS.
- [Gauge](gauge/): a value within a range on a ring.
- [QR Code](qr-code/): a link or a code for the camera of a phone.

**Controls**

- [Button](button/): runs a closure when the user taps, clicks or presses it.
- [Toggle](toggle/): a switch for a setting that takes effect at once.
- [Slider](slider/): picks a number from a range by dragging a knob.
- [Circular Slider](circular-slider/): a slider on a ring, for a thermostat or a dial.
- [Color Picker](color-picker/): a colour from a grid, a spectrum or sliders, with opacity and hex code.
- [Color Well](color-well/): a swatch that opens the colour picker in a popover.
- [Segmented Control](segmented-control/): a row of mutually exclusive choices.
- [Text Field](text-field/): one line of editable text.
- [Text Area](text-area/): editable text of several lines, wrapped and scrolled.
- [Code Editor](code-editor/): source code with line numbers, colors by its syntax and marks where it is wrong.
- [Secure Field](secure-field/): a password or a PIN, shown as dots.
- [Wheel Picker](wheel-picker/): one or more turning wheels to choose values from, as on iOS.
- [Date and Time Wheels](date-wheel/): a date or a time of day on wheels.
- [Calendar](calendar/): a date on a month grid that pages sideways.
- [Stepper](stepper/): a minus and a plus button that change a number a step at a time.
- [Search Field](search-field/): a text field with a magnifying glass and a clear button.
- [Page Control](page-control/): a row of dots that shows and turns the current page.
