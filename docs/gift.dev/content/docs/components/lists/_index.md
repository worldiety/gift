List components show collections. Pick by the number of items: a list builds every item, a virtual list and an
image gallery build only what is on screen.

- [List](list/): a short, grouped list of rows with separators and section headers.
- [Row](row/): the standard list item with icon, title, subtitle, value, accessory and chevron.
- [Virtual List](virtual-list/): very long lists of uniform rows, with selection and keyboard control.
- [Image Gallery](image-gallery/): a scrolling masonry or justified grid of thousands of pictures.
