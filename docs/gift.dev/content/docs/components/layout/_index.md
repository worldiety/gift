Layout components arrange and frame other views. [Layout](../../concepts/layout/) explains how they divide the
space between their children.

- [Stack](stack/): `VStack` and `HStack` place children one after another along an axis.
- [ZStack](zstack/): draws its children on top of each other.
- [Window](window/): wraps the root view in the window background.
- [Box](box/): a styled rectangle without children.
- [Spacer](spacer/): an invisible, flexible gap that pushes its neighbors apart.
- [Card](card/): a raised panel with rounded corners and an optional header.
- [Scroll View](scroll-view/): `VScroll` and `HScroll` move content that does not fit.
